Discovery

Create a key in the Google Cloud Console and enable the "YouTube Data API v3". Each search costs API quota — the default free quota is 10,000 units/day (~100 searches; "All DJs" uses one search per DJ).

Plex

Enables a "Play in Plex" button on the Analytics tab's file cards, deep-linking into Plex Web. Requires a Plex library already scanning the same audio output directory. Find your token at support.plex.tv → "Finding an authentication token". If you have more than one music library in Plex, set Library Section to the exact name of the one DJDownload writes to — otherwise the first one Plex reports is used, which may be the wrong one.
